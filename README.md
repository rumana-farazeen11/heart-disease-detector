# Heart Disease Risk Detector

A beginner machine learning project that estimates heart disease risk
from clinical measurements, using the UCI Cleveland Heart Disease dataset.
Built with Python, scikit-learn, and Streamlit.

**Educational demo only. Not medical advice.**

## Run locally
1. `pip install -r requirements.txt`
2. `python train_model.py`
3. `streamlit run app.py`

## Dataset
UCI Machine Learning Repository: Heart Disease (Cleveland).
